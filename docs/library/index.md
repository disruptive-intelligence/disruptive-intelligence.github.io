# Bibliothèque

!!! abstract "À quoi sert cette partie"
    Mes notes de **compréhension** : cours reformulés, synthèses, concepts.
    Plus longues et plus explicatives que les fiches Pentest, qui restent l'outil opérationnel.

| Pentest | Bibliothèque |
|---|---|
| Retrouver une commande en quelques secondes | Comprendre un sujet en profondeur |
| Fiches courtes, checklists | Notes de cours, synthèses |
| Utilisé pendant un CTF | Utilisé pour apprendre et réviser |

!!! note "Import"
    Les notes arrivent depuis Obsidian **une par une**, relues (secrets, syntaxe, images) avant publication.
