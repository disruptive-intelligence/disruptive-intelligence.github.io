Ce cours passe en revue les journaux réseau qu’un SOC exploite pour reconstituer une attaque : **NetFlow**, **pare-feu**, **VPN**, **proxy**, **IDS / IPS**, **WAF**, **logs web** et **DNS**. Chaque source répond à des questions différentes ; la synthèse finale indique laquelle consulter selon ce que l’on cherche.

Côté poste de travail, les journaux Windows (dont le pare-feu Windows) sont traités dans [Analyse des journaux d'événements Windows (Event Logs)](../../windows/analyse-des-journaux-d-evenements-windows-event-logs/index.md).
