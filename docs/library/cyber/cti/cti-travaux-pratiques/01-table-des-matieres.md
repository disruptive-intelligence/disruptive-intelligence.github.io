### Comment lire les blocs de ce cours

| Bloc | Signification |
|---|---|
| 🔴 **FIL ROUGE** | Épisode du cas HELIOMED, daté, avec une décision et un livrable |
| 🎯 **ET MAINTENANT ?** | Micro-décision concrète. Une situation, une question, une réponse argumentée |
| 🧪 **EN PRATIQUE** | Procédure, grille, formulation réutilisable |
| 🔬 **MINI-LAB** | Exercice avec données, durée, difficulté, corrigé commenté |
| ⚠️ **PIÈGE** | Erreur fréquente, raisonnement fautif, faux sentiment de maîtrise |
| 📌 **LIMITES** | Ce qui ne fonctionne pas, ce qui n'est pas couvert, coût réel |
| ✅ **BONNE PRATIQUE** | Recommandation priorisée P0 / P1 / P2 |
| ⚖️ **CADRE** | Contrainte juridique, contractuelle ou déontologique |
| ⏱ **ÉTAT DE L'ART** | Donnée datée, avec sa source et sa date de vérification. **Périssable** |
| 🖼 **SCHÉMA** | Emplacement d'un visuel à produire en mise en page. Le texte reste autonome sans lui |
| 📎 **SOURCE** | Renvoi au registre de sources, annexe M |

**Règle éditoriale sur les faits datés.** Un fait daté n'est jamais un pilier du raisonnement : il l'illustre. **Si vous supprimez tous les blocs ⏱, le cours doit rester intégralement valide.** Le test appliqué à chaque bloc : *si ce fait était faux ou périmé, quel enseignement s'effondrerait ?* La réponse doit être « aucun ».

**Règle éditoriale sur les notions analytiques.** Ce cours emprunte à des disciplines voisines — logique, méthode scientifique, sciences cognitives. Chaque emprunt doit passer un test : *en quoi cela permet-il à un analyste de produire un meilleur renseignement ?* Si la réponse n'est pas immédiate et concrète, le développement n'a pas sa place ici. ## Si vous venez du cours MCS

Ce cours se lit seul. Mais si vous avez suivi le précédent, ce tableau vous situe immédiatement.

| | **MCS** | **CTI** |
|---|---|---|
| Objectif | Réduire l'**exposition** | Réduire l'**incertitude** |
| Modèle mental | La boucle MCS | La boucle analytique |
| Décision centrale | Que corriger, quand | **Que croire, et avec quelle confiance** |
| Objet de travail | Des actifs | Des informations |
| Livrable principal | Un plan de remédiation prouvé | Un jugement analytique calibré |
| Mesure de réussite | Exposition résiduelle, prouvée | Décisions modifiées, confiance justifiée |
| Le piège symétrique | Corriger sans connaître son périmètre | Collecter sans savoir ce qu'on cherche |
| Ce qui ne s'automatise pas | La décision d'accepter un risque | Le jugement |

**Ce que vous retrouverez** : la primauté du besoin sur l'outil · la méfiance envers les chiffres non qualifiés · l'obligation de dire ce qu'on ne sait pas · la preuve comme partie intégrante du travail.

**Ce qui change, et c'est fondamental** :

> **En MCS, le réel est vérifiable.** Un serveur porte une version ou n'en porte pas. On peut aller regarder.
> **En CTI, le réel est inaccessible.** On ne vérifie jamais une hypothèse, on la rend plus ou moins probable.

C'est de cette phrase que découlent toutes les particularités du métier : pourquoi on exprime des niveaux de confiance, pourquoi on calibre son langage, pourquoi on argumente au lieu de démontrer, et pourquoi un bon analyste dit régulièrement « je ne sais pas » sans que ce soit un aveu d'incompétence.
