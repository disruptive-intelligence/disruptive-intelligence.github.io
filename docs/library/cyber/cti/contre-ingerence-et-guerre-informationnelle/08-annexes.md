## Annexe A — Glossaire

## Annexe B — Framework DISARM : matrice de référence

Le framework DISARM (anciennement AMITT) est structuré en quatre grandes phases, chacune contenant des tactiques et des techniques. La traduction française ci-dessous est basée sur la version publiée par VIGINUM (février 2024).

**Phase 1 — Planification.** TA01 : Planifier la stratégie. TA02 : Planifier les objectifs. TA13 : Analyser les publics cibles.

**Phase 2 — Préparation.** TA14 : Élaborer les récits (T0003 : Exploiter des récits existants, T0004 : Développer des récits contradictoires, T0022 : Exploiter des théories conspirationnistes, T0040 : Demander des preuves irréfutables, T0068 : Exploiter les événements d'actualité, T0082 : Élaborer de nouveaux récits, T0083 : Intégrer les vulnérabilités des audiences cibles). TA05 : Fabriquer du contenu. TA15 : Mettre en place des ressources informationnelles. TA06 : Établir la confiance. TA14 : Microcibler. TA16 : Sélectionner des canaux et des fonctionnalités.

**Phase 3 — Exécution.** TA07 : Diffuser le contenu. TA08 : Amplifier le contenu (T0049 : Amplification par des trolls, T0097 : Création d'avatars). TA09 : Maximiser l'exposition.

**Phase 4 — Évaluation.** TA10 : Évaluer l'efficacité.

**Mapping vers les chapitres du cours :**

| Tactique DISARM | Chapitre(s) du cours |
|----------------|---------------------|
| Planifier la stratégie / Analyser les publics cibles | Ch.6, Ch.10 |
| Élaborer les récits | Ch.14 |
| Fabriquer du contenu | Ch.8, Ch.15 |
| Mettre en place des ressources informationnelles | Ch.7 |
| Microcibler | Ch.10 |
| Diffuser / Amplifier | Ch.7, Ch.9 |
| Évaluer l'efficacité | Ch.14 (évaluation d'impact) |

## Annexe D — Templates opérationnels

### D.1 Fiche de signalement d'un phénomène inauthentique

**Identifiant :** [AAAA-MM-JJ-NNN] | **Date de détection :** | **Analyste :**

**Source du signalement :** ☐ Monitoring interne ☐ Plateforme ☐ Société civile ☐ Partenaire ☐ Signalement citoyen

**Description synthétique :** [2-3 phrases]

**Indicateurs observés :** Nombre de comptes impliqués, fenêtre temporelle, URLs identifiées, plateformes concernées, volumétrie.

**Qualification initiale :** ☐ Probable CIB ☐ Probable organique ☐ Indéterminé ☐ Spam commercial

**Critères INE :** Contenu trompeur ☐ Oui ☐ Non ☐ Zone grise | Diffusion artificielle ☐ Oui ☐ Non | Atteinte aux intérêts fondamentaux ☐ Oui ☐ Non ☐ Potentiellement | Implication étrangère ☐ Oui ☐ Non ☐ Non démontré

**Recommandation :** ☐ Classement ☐ Surveillance renforcée ☐ Investigation approfondie ☐ Signalement immédiat

### D.2 Checklist d'analyse de réseau coordonné

☐ Identification du corpus initial (comptes, contenus, URLs)
☐ Analyse de synchronicité temporelle (fenêtres de publication)
☐ Construction du graphe d'interactions (retweets, mentions, URLs communes)
☐ Détection de clusters (algorithme de Louvain/Leiden)
☐ Identification des nœuds centraux (centralité de degré, d'intermédiarité)
☐ Analyse des photos de profil (détection IA, cohérence)
☐ Analyse des horaires d'activité (fuseau horaire implicite)
☐ Analyse d'infrastructure (Whois, reverse IP, certificats)
☐ Comparaison avec des TTPs documentés
☐ Évaluation du ratio authentique/inauthentique
☐ Documentation des niveaux de confiance

### D.3 Grille d'évaluation de crédibilité d'un contenu

| Critère | Score (1-5) | Observations |
|---------|------------|-------------|
| Source identifiable et vérifiable | | |
| Cohérence interne du document | | |
| Métadonnées cohérentes | | |
| Corroboration par des sources indépendantes | | |
| Contextualisation factuelle vérifiable | | |
| Absence d'artefacts techniques (IA, montage) | | |
| Antécédents de la source (crédibilité historique) | | |
| **Score global** | **/35** | |

> Les scores 1-2 = faible crédibilité, 3 = zone grise, 4-5 = crédibilité élevée. Un score global < 15 indique une crédibilité faible. Ce score est un outil d'aide, pas un verdict.

## Annexe F — Cadre juridique comparatif

| Dimension | France | UE | États-Unis | Royaume-Uni |
|-----------|--------|-----|-----------|-------------|
| **Institution de référence** | VIGINUM (SGDSN) | EEAS StratCom | Pas d'équivalent centralisé | FCDO Counter-Disinformation Unit |
| **Cadre législatif** | Loi manipulation information (2018), décrets VIGINUM (2021) | DSA (2024-2025), Code de pratique désinformation | Premier Amendement — protection très large, FARA (agents étrangers) | Online Safety Act (2023) |
| **Qualification juridique** | INE (4 critères cumulatifs) | FIMI (cadre analytique, pas juridique) | Pas de qualification spécifique — First Amendment | « Inauthentic behaviour » (cadre souple) |
| **Sanctions** | Signalement plateformes, action diplomatique, sanctions UE | Sanctions UE (Social Design Agency, Tigerweb, Dougan) | Sanctions OFAC, indictments DOJ | Sanctions autonomes, FCDO attributions |
| **Accès aux données** | DSA (chercheurs agréés), données VIGINUM encadrées par décret | DSA Art. 40 (accès chercheurs) | Pas de cadre fédéral d'accès | OSA obligations de transparence |
| **Limites** | Périmètre limité aux INE étrangères, pas aux manipulations domestiques | Application du DSA encore en développement | Forte protection constitutionnelle de l'expression, fragmentation institutionnelle | Cadre récent, mise en œuvre en cours |

---

> **Note finale.** Ce cours est un document de référence conçu pour être exploité par un praticien. Il n'est pas un manuel de manipulation — il vise à comprendre les mécanismes d'influence pour mieux les détecter, les qualifier et les contrer. La rigueur analytique, la prudence attributive et le respect du cadre juridique sont les conditions d'exercice du métier d'analyste en guerre informationnelle.
