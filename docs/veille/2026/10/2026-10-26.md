### ▸ Un fichier AGENTS.md piégé dans un dossier Téléchargements pousse un agent de code IA à installer un paquet npm malveillant
<!-- selection: event:evt-9d81e5a8-43d2-4db2-b220-1375b1349bb4 freshness:new -->

**Le fait :** Des chercheurs de Forever Security ont découvert chez un client un fichier d'instructions AGENTS.md malveillant placé dans le dossier Téléchargements, qui servait aussi de répertoire de travail à un agent de code IA. L'agent, qui charge automatiquement ces fichiers, a tenté d'installer le paquet npm malveillant « function-color ». Les chercheurs ont reproduit l'attaque contre OpenAI Codex et démontré une technique proche contre Claude Code pour exfiltrer des jetons OAuth et détourner le compte, à l'aide des seules instructions.

**Pourquoi c'est important :** Ces fichiers ne sont pas des exécutables, mais l'agent agit avec les outils et permissions qui lui sont accordés : un simple texte déposé au bon endroit devient un vecteur d'exécution de code et de vol d'identifiants. « Il n'y a rien à corriger pour OpenAI ou Anthropic », notent les chercheurs : la défense relève de la configuration et des droits accordés aux agents.

**Conséquences possibles :** Les entreprises qui déploient des agents de code doivent restreindre leurs répertoires de travail et leurs droits d'installation, sous peine d'ouvrir une nouvelle voie d'attaque de la chaîne d'approvisionnement logicielle.

**Source :** [BleepingComputer — « AI coding agents hijacked using AGENTS.md file in Downloads folder »](https://www.bleepingcomputer.com/news/security/ai-coding-agents-hijacked-using-agentsmd-file-in-downloads-folder/)

## Lexique du jour

- **AGENTS.md** — Fichier texte placé dans un projet pour donner à un agent de code IA ses consignes (outils, tests, conventions). L'agent le charge automatiquement, ce qui en fait un vecteur d'attaque s'il est piégé.
- **AUTOWARCOM** — Autonomous Warfare Command, commandement de combat américain dédié aux systèmes autonomes voulu par Pete Hegseth, appelé à devenir l'acheteur officiel du Pentagone pour ces technologies.
- **Loi de réconciliation** — Procédure budgétaire du Congrès américain permettant d'adopter certaines mesures financières à la majorité simple au Sénat ; le financement de démarrage d'AUTOWARCOM en dépend.
- **SD-WAN** — Réseau étendu piloté par logiciel, qui relie les sites d'une entreprise et se gère depuis une console centrale, comme VeloCloud Orchestrator : compromettre cette console donne la main sur tout le réseau.
- **Covered List** — Liste officielle de la FCC recensant les entreprises dont les produits de communication et de vidéosurveillance sont jugés menaçants pour la sécurité nationale américaine ; HiSilicon y figure.
- **ARM Neoverse V3** — Cœurs de processeur conçus par le britannique ARM pour les serveurs et le calcul haute performance, réutilisés par Alcor Micro et donc par le futur Rhea2 de SiPearl.
- **CRTA** — Organisation indépendante serbe d'observation électorale, dont les projections ont donné la Liste étudiante gagnante des législatives du 25 octobre.
- **Houthis** — Mouvement armé yéménite soutenu par l'Iran, qui contrôle une partie du Yémen et mène des attaques de missiles et de drones contre l'Arabie saoudite.
- **PHP2Shell** — Nom donné aux failles critiques de PHP (CVE-2026-109618 et -109619) permettant d'exécuter du code à distance sans authentification sur les serveurs web.
